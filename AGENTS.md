# Istruzioni per assistenti AI

Questo repository contiene gli appunti del corso di Machine Learning e il sito interattivo che li presenta.
Le istruzioni valgono per qualsiasi assistente (Claude, Codex, Cursor, Copilot, …):

1. Leggere `CLAUDE.md` (panoramica, regole, comandi).
2. Prima di lavorare su una lezione, leggere **tutta** `docs/GUIDA-LEZIONI.md` e `docs/STATO.md`.
3. Usare come modello le lezioni già fatte (`website/src/content/lessons/`, `website/src/widgets/`).
4. Rispondere in italiano.

La skill per Claude Code `.claude/skills/nuova-lezione/SKILL.md` descrive la procedura passo passo e
può essere seguita anche da altri assistenti come checklist.
